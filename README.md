# NXGN UPLINK — EVIL⁶⁶⁶ MD pairing site

Futuristic WhatsApp pairing portal for the EVIL⁶⁶⁶ MD bot fleet.
Zero npm dependencies — plain Node only.

## Env vars (Railway → Variables)

| Variable | Value |
|---|---|
| SEYORI_PANEL_URL | https://victorylordhimselfofficial.seyori.name.ng |
| SEYORI_PANEL_KEY | server-1 client API key (ptlc_…) |
| SEYORI_PANEL_SERVER | server-1 uuid |
| SEYORI_PANEL2_KEY | server-2 client API key |
| SEYORI_PANEL2_SERVER | server-2 uuid |
| SEYORI_PANEL3_KEY | server-3 client API key |
| SEYORI_PANEL3_SERVER | server-3 uuid |

Deploy: connect this repo on Railway, it auto-runs `node server.js`.
